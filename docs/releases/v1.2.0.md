# WebClone Ultimate v1.2.0

**La memoria visual de la web.** WebClone Ultimate captura el DOM y el CSSOM vivos, reconstruye los
recursos, conserva la red observada y exporta un paquete autónomo que se puede abrir sin el servidor
original, sin conexión y sin la extensión.

Esta release publica **dos paquetes de instalación** generados desde el mismo código: uno para
navegadores Chromium y otro para Firefox. La diferencia está en el manifiesto y en el modelo de
ejecución en segundo plano de cada navegador; las funciones de captura, reproducción y exportación
son las mismas.

## Descargas

| Componente | Archivo | Requisitos | Instalación |
|---|---|---|---|
| Chrome, Chromium y Edge | `webclone-ultimate-chrome-1.2.0.zip` | Chrome/Chromium/Edge 116+ | Cargar descomprimida |
| Firefox | `webclone-ultimate-firefox-1.2.0.zip` | Firefox 128+ | Complemento temporal |
| Comprobación de integridad | `SHA256SUMS.txt` | — | `sha256sum -c SHA256SUMS.txt` |

> Los archivos ZIP son paquetes de extensión, no instaladores. Chrome necesita que se descomprima el
> ZIP antes de cargarlo. Firefox puede cargar el complemento temporal desde la carpeta descomprimida.
> Ninguno de los dos paquetes incluye actualizaciones automáticas.

## Chrome, Chromium y Edge

**Archivo:** `webclone-ultimate-chrome-1.2.0.zip`

**Build:** Manifest V3 con `background.service_worker`, empaquetado con esbuild para el objetivo
`chrome116`.

**Cuándo usarla:** es la build recomendada para el uso diario y para Chromium, Edge y navegadores
compatibles con extensiones de Chrome. Es también la build utilizada por la suite E2E automatizada.

**Instalación:**

1. Descarga el ZIP y descomprímelo en una carpeta permanente.
2. Abre `chrome://extensions` en Chrome o Chromium, o `edge://extensions` en Edge.
3. Activa **Modo de desarrollador**.
4. Pulsa **Cargar descomprimida**.
5. Selecciona la carpeta que contiene `manifest.json`, no el ZIP.
6. Fija el icono de WebClone Ultimate en la barra si quieres tenerlo a mano.

**Importante:** esta build no es un `.crx` firmado y no se instala con doble clic. Tampoco está
publicada en Chrome Web Store, por lo que no recibe actualizaciones automáticas. Para actualizar,
descarga una release nueva y vuelve a cargar la carpeta. No necesitas Node.js para instalar o usar
este paquete.

## Firefox

**Archivo:** `webclone-ultimate-firefox-1.2.0.zip`

**Build:** Manifest V3 con `background.scripts`, `browser_specific_settings.gecko.id` y
`strict_min_version: 128.0`. Los hooks que Chromium ejecuta en el mundo MAIN se inyectan mediante
`scripting.executeScript`, que es la ruta compatible con Firefox.

**Cuándo usarla:** para Firefox 128 o superior. La build conserva las cuatro modalidades de captura,
el reproductor, el ZIP verificable y el mismo motor de privacidad que la versión de Chromium.

**Instalación:**

1. Descarga el ZIP y descomprímelo en una carpeta permanente.
2. Abre `about:debugging#/runtime/this-firefox`.
3. Pulsa **Cargar complemento temporal**.
4. Selecciona el archivo `manifest.json` de la carpeta descomprimida.
5. Concede el acceso a los sitios que quieras capturar cuando Firefox lo solicite.

**Importante:** Firefox instala este paquete como **complemento temporal**. Al cerrar el navegador
se elimina y hay que volver a cargarlo. El ZIP no es un `.xpi` firmado y no se actualiza solo. Para
una instalación permanente hay que firmar la extensión en AMO; el proyecto no distribuye una build
firmada. El runtime de Firefox se valida con `web-ext lint`, pero no está automatizado con Playwright
en esta release.

## Qué incluye la extensión

Las dos builds comparten estas capacidades:

| Modo | Qué conserva | Uso recomendado |
|---|---|---|
| **Instant Clone** | DOM, CSS, imágenes, fuentes, formularios, scroll, canvas, shadow DOM e iframes same-origin | Archivar una página tal y como se ve |
| **Clon dinámico** | HTML fuente, JavaScript local y respuestas `fetch`/XHR observadas | Reproducir una página que se hidrata o pide datos |
| **Clon Completo** | Todo lo anterior más ruta, storage no sensible y journal de red de una sesión interactiva | Reproducir un recorrido con formularios y navegación |
| **Full Session Recording** | Eventos rrweb, timeline, errores, navegación SPA y red | Revisar la evolución temporal de una sesión |

También incluye:

- Selector de pestaña, fases de captura en tiempo real y progreso.
- Inspector de captura con recursos correctos, fallos y alternativas.
- Historial de sesiones con tamaño, integridad y fecha.
- Exportación ZIP con checksums SHA-256, reproductor autónomo y servidor local opcional.
- Importación que verifica la integridad sin descartar una sesión dañada.
- Reproductor rrweb con timeline, velocidades de 0.25× a 4×, errores y red.
- Exclusión de contraseñas, campos ocultos, datos de pago, cookies, tokens y storage sensible.
- Procesamiento íntegramente local: no hay telemetría ni subida de capturas.

### Contenido del ZIP de instalación

```text
manifest.json
background.js
content.js
main-world.js
popup/
replay/
vendor/wc-replay.js
icons/
serve-clone.mjs
```

El paquete contiene JavaScript compilado y los recursos necesarios para ejecutar la extensión. No
incluye `node_modules`, código fuente TypeScript ni tests. No lo confundas con el **ZIP de captura**
que genera la extensión: ese segundo paquete contiene el DOM, los assets, la sesión y el reproductor
de una página concreta.

## Privacidad y límites

- No se guardan cookies, cabeceras `Authorization` ni credenciales en el ZIP exportado.
- Las contraseñas, campos ocultos, `one-time-code`, datos de pago y claves de storage sensibles se
  excluyen y se registran en `omittedKeys`.
- El HTML y la red capturados sí pueden contener información visible de la cuenta. **Revisa siempre
  el ZIP antes de compartirlo.**
- No se pueden capturar páginas internas como `chrome://` o `about:`, PDFs nativos, la Chrome Web
  Store ni iframes cross-origin.
- El Clon Completo es determinista: reproduce la red que se observó, no genera peticiones nuevas.

Consulta la lista completa en
[LIMITATIONS.md](https://github.com/D1se0/webclone-ultimate/blob/v1.2.0/LIMITATIONS.md).

## Validación de esta versión

Antes de publicar la release se comprobó:

- TypeScript estricto sin errores.
- **48/48** tests unitarios de la extensión.
- **8/8** tests E2E con Chromium y la extensión real.
- Build independiente de Chrome y Firefox.
- `web-ext lint`: **0 errores** y 9 avisos no bloqueantes.
- ZIPs de Chrome y Firefox generados por `npm run package`.
- **6/6** tests unitarios y **12/12** E2E de la web en escritorio y móvil.
- Build estático de la web validado para GitHub Pages.
- Sitio público y assets respondiendo correctamente.

El workflow de release vuelve a ejecutar typecheck, tests unitarios, build, empaquetado y
`web-ext lint` antes de crear la release. Los ZIP publicados aquí son los generados por ese workflow.

## Verificar las descargas

El archivo `SHA256SUMS.txt` contiene el hash SHA-256 de cada ZIP. Descarga los tres archivos en la
misma carpeta y ejecuta:

```bash
sha256sum -c SHA256SUMS.txt
```

En macOS puedes usar `shasum -a 256 -c SHA256SUMS.txt`. En Windows, compara el resultado de
`Get-FileHash .\webclone-ultimate-chrome-1.2.0.zip -Algorithm SHA256` con la línea correspondiente.
