# Código de conducta

## Nuestro compromiso

Queremos un espacio abierto, respetuoso y técnico. Se aceptan personas de cualquier experiencia,
identidad y contexto. No se toleran acosos, ataques personales, discriminación ni divulgación de datos
privados.

## Comportamiento esperado

- Crítica concreta sobre el código y las decisiones, no sobre las personas.
- Explicar el contexto y aportar evidencia reproducible.
- Respetar las limitaciones y la privacidad de terceros.
- Aceptar que una propuesta se rechace por alcance, mantenimiento o seguridad.

## Comportamiento inaceptable

- Insultos, amenazas, acoso o comentarios discriminatorios.
- Publicar capturas, tokens, cookies o información personal de otras personas.
- Spam, suplantación de identidad o manipulación de discusiones.
- Abrir issues con instrucciones para atacar sistemas ajenos.

## Aplicación

Los mantenedores pueden editar o eliminar comentarios, cerrar issues y bloquear cuentas cuando sea
necesario. Para reportar un incidente, usa el canal privado de seguridad o contacta con el mantenedor
del repositorio. Las decisiones se tomarán buscando la seguridad y la continuidad del proyecto.
